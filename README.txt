PAGAL ❤️ MUHTRMA — MOBILE-FRIENDLY PHOTO PUZZLE

ALL FILES IN ONE FOLDER
index.html, style.css, script.js, and all 7 photos are together in this same folder. No images subfolder is needed.

DESKTOP
1. Extract this ZIP.
2. Open the Pagal_Muhtrma_Puzzle_Mobile folder.
3. Open index.html in Chrome or Edge.

MOBILE (iPhone / Android)
For reliable play, use an HTML preview/code-editor app that supports JavaScript and local files, or upload these files to a static website host such as GitHub Pages or Netlify and open the resulting link in Safari/Chrome. Some phone file previews (including iPhone Quick Look) do not run interactive HTML games correctly.
Keep index.html, style.css, script.js, and photo-1.jpg through photo-7.jpg together in one folder when uploading.
On touch screens, tap a puzzle piece, then tap its destination.

SAVE & RESUME
Progress saves in the same browser on the same device. Private browsing, cleared browser data, or changing browsers/devices may remove or hide saved progress.

FEATURES
- 7 included photos
- Wooden, Romantic, and Galaxy themes
- Classic square and heart-shaped puzzle
- 3x3, 4x4, 5x5, 6x6, and 8x8 difficulty
- Touch tap-to-place and desktop drag-and-drop
- Move count, timer, hint, fullscreen, celebration and auto-next level

NOTE
The game uses HTML, CSS and JavaScript. Google Fonts needs internet; fallback fonts are used offline.
